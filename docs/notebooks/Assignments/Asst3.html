  1. Consider an infectious disease which has recently been introduced into a very large population from wildlife. It is believed that the offspring distribution can be well-approximated by a Negative-Binomial distribution of unknown parameters. There have been five known independent introductions into the population. So far all outbreaks have died out, but there is concern that the reproduction number (the mean of the offspring distribution) may be larger than \(1\). We will use the parametrization of the Negative Binomial distribution from Example 1.11.

    (a) Find the probability of an outbreak of size \(L\) for a given \(p\) and \(r\) (\(r\) may not be an integer). Your expression should be given in terms of the Gamma function \(\Gamma(x)\) — replace all factorials \(M!\) with \(\Gamma(M+1)\). It will be helpful to observe that if \(\mu_{r,p}(x)\) is the PGF of the distribution, then \(\mu_{r,p}(x)^N\) is the PGF for another Negative Binomial distribution.

    Solution (a)

    In this model, each node in the Galton-Watson tree represents a distinct individual. So the number of infections is equal to the number of nodes in the tree. Following Size distribution of small outbreaks Section 4.5.1, the size of the outbreak is \(L\) with probability

    \[\begin{align*} \mathbb{P}[\text{outbreak of size $L$}] &= \frac{1}{L} [x^{L-1}] \mu_{r,p}(x)^L\\ &= \frac{1}{L} [x^{L-1}] \left(\left(\frac{p}{1-(1-p)x}\right)^r\right)^L\\ &= \frac{1}{L}[x^{L-1}] \mu_{rL,p}(x)\\ &= \frac{1}{L}[x^{L-1}] \frac{\Gamma(N+rL)}{N! \,\Gamma(rL)}p^{rL} (1-p)^N x^N\\ &= \frac{1}{L} \frac{\Gamma(L-1+rL)}{(L-1)! \,\Gamma(rL)}p^{rL}(1-p)^{L-1} \end{align*}\]

    (b) Find a reasonably simplified formula for the probability that \(M\) outbreaks have sizes \(L_1\), \(L_2\), \(\ldots\), \(L_M\) for given parameters \(p\) and \(r\) (expressed in terms of Gamma functions)

    Solution (b)

    As these are independent, it is just the product:

    \[\begin{align*} \mathbb{P}[L_1,L_2,\ldots, L_m] &= \prod_{i=1}^M \frac{1}{L_i} \frac{\Gamma(L_i-1+rL_i)}{(L_i-1)! \,\Gamma(rL_i)}p^{rL_i}(1-p)^{L_i-1}\\ &= \frac{1}{\prod_{i=1}^M L_i} \left(\prod_{i=1}^M \frac{\Gamma(L_i-1+rL_i)}{(L_i-1)! \, \Gamma(rL_i)}\right) p^{r\sum L_i}(1-p)^{-M + \sum L_i} \end{align*}\]

    The probability of observing data for a given set of parameters is called the likelihood of the parameters. The log-likelihood is the logarithm of the likelihood. The parameters that maximize the likelihood will also maximize the log-likelihood, but maximization is often easier with log-likelihood, and also much easier to use computationally. In Python, we can calculate \(\ln \Gamma(x)\) using

    from scipy.special import gammaln  #put this at the top

gammaln(x)

    (c) Find the log-likelihood of \(p\) and \(r\) given \(L_1, \ldots, L_M\).

    Solution (c)

    We just take logarithms, recalling that the logarithm of a product is the sum of the logarithms.

    We use \(\log\Gamma(x)\) for \(\ln(\Gamma(x))\)

    \[\begin{align*} \text{Log-likelihood}(r,p) &= + r \ln(p) \sum L_i + \ln(1-p)\left(-M+ \sum L_i\right)\\ &\quad + \sum_{i=1}^M {\Large(}-\ln L_i + \log\Gamma (L_i-1 + r L_i) - \ln ((L_i-1)!) - \log\Gamma(rL_i){\Large)} \end{align*}\]

    (d) Using \(A = \sum L_i\), find a function \(\hat{p}(r)\) that maximizes the likelihood given \(r\).

    Solution (d)

    Holding \(r\) fixed, we differentiate with respect to \(p\).

    \[\begin{align*} \frac{\partial}{\partial p} \text{Log-likelihood}(r,p) &= Ar \frac{1}{p} - \frac{A-M}{1-p}\\ \Rightarrow 0 &=Ar \frac{1}{\hat{p}} - \frac{A-M}{1-\hat{p}}\\ &= (1-\hat{p})Ar - (A-M)\hat{p}\\ \Rightarrow \hat{p} &= \frac{Ar}{A(r+1)-M} \end{align*}\]

    Note - for any \(r\) this is a maximum.

    (e) Write down a function in terms of only \(r\) to maximize to find \((p^*,r^*)\) that maximizes the likelihood. Remove any terms that do not depend on \(r\).

    Solution (e)

    We substitute this in for \(p\) in the log-likelihood and then differentiate with respect to \(r\):

    \[\begin{align*} \text{Log-likelihood}(r,\hat{p}(r)) &= + Ar \ln\left(\frac{Ar}{A(r+1)-M}\right) + (A-M)\ln\left(1-\frac{Ar}{A(r+1)-M}\right)\\ &\quad + \sum_{i=1}^M {\Large(}-\ln L_i + \log\Gamma (L_i-1 + r L_i) - \ln ((L_i-1)!) - \log\Gamma(rL_i){\Large)} \end{align*}\]

    So to maximize this, we can maximize the function

    \[\begin{align*} f(r) &= Ar \ln\left(\frac{Ar}{A(r+1)-M}\right) + (A-M)\ln\left(1-\frac{Ar}{A(r+1)-M}\right)\\ &\quad + \sum_{i=1}^M {\Large(}\log\Gamma (L_i-1 + r L_i)- \log\Gamma(rL_i){\Large)} \end{align*}\]

    (f) One way to estimate parameters is “Maximum Likelihood Estimation” (MLE). We simply find the parameters that have the highest likelihood.

    The following code simulates numsims\(=5\) outbreaks with a negative binomial offspring distribution having \(r=1\), \(p=0.6\). Then it uses maximum likelihood estimation to estimate \(r\) and \(p\).

    • Reflect on your observations. What happens if numsims is small? What if \(\mathcal{R}_0\) is close to 1?

    Solution (f)

    See code below.

    We need a large number of simulations to have good estimates for \(p\) and \(r\). However, well before \(p^*\) and \(r^*\) are a very close match the offspring distribution fits well. Thus the outcomes will be accurately predicted event if \(p\) and \(r\) are not well-identified.

    If \(\mathcal{R}_0\) is close to \(1\), we need higher certainty about its value to make good predictions for the future (the policy implications of being unsure if \(\mathcal{R}_0 =0.5\) or \(0.95\) are small compared to the implications of uncertainty about whether \(\mathcal{R}_0 = 0.95\) or \(1.05\)).

import numpy as np
from scipy.special import gammaln
from scipy.optimize import minimize_scalar
import matplotlib.pyplot as plt

r = 0.8
p = 0.45
numsims = 5000

if    (1-p)*r/p >= 1:
    raise ValueError("Warning: mean must be less than 1 for extinction to be certain")


L=[]
for counter in range(numsims):
    X = 1
    cumulative = X
    while X>0:
        newX = 0
        for i in range(X):
            U = np.random.negative_binomial(r,p)
            cumulative += U
            newX += U
        X = newX
    L.append(cumulative)


print("observed sizes: ", L)
L = np.array(L)
A = L.sum()



#print("student-created function is needed here, using default")
def F_to_maximize(r):
    f = A*r*np.log(A*r/(A*(r+1)-numsims)) + (A-numsims)*np.log(1-A*r/(A*(r+1)-numsims))
    for Li in L:
        f += gammaln(Li - 1 + r*Li) - gammaln(r*Li)
    return f
def F_to_minimize(r):
    return -F_to_maximize(r)


res = minimize_scalar(F_to_minimize, bounds=(1e-8, 1e6), method="bounded")

r_est = res.x

#print("student-created function is needed here, using default")
p_est = A*r_est/(A*(r_est+1)-numsims)#\frac{Ar}{A(r+1)-M}

print("Estimated r:", r_est)

    The coefficient of \(y^n\) is the probability of \(n\) end cells and \(0\) stem cells.

    (e) What recursive relation does \(\omega_g(y)\) solve? Assume \(\omega_g(y) \to \omega(y)\) converges as \(g \to \infty\). What quadratic (in \(\omega\)) equation does the recursive relation become in this limit?

    Solution (e)

    We have

    \[\begin{align*} \omega_{g+1}(y) &= \Phi_{g+1}(0,y)\\ &= p_0 y + p_2 \Phi_{g}(0,y)^2\\ &= p_0 y + p_2 \omega_g(y)^2 \end{align*}\]

    As \(g \to \infty\), we conclude \(\omega(y) = p_0y + p_2 \omega(y)^2\)

    (f) Solve the quadratic equation for \(\omega(y)\). There should be two options. Based on our knowledge of the system, what is \(\omega(0)\)? Use this to choose the correct result. Your result should have a \(\sqrt{1-4p_0p_2y}\) in it,

  2. Consider a continuous-time version of the Macken-Perelson model. Assume stem cells divide with rate \(r_s\) and the mast cells divide with rate \(r_m\). Assume the system begins with a single stem cell. Let \(\Phi(x,y,z,t)\) be the PGF for the number of each type at time \(t\).

    (a) Derive a backward Kolmogorov equation for \(\Phi(x,y,z,t)\)

    Solution (a)

    We introduce \(\Phi_s(x,y,z,t)\), \(\Phi_m(x,y,z,t)\), and \(\Phi_e(x,y,z,t)\) to be the PGFs assuming an initial stem, mast or end cell.

    We can quickly see \(\Phi_e(x,y,z,t) = z\).

    The offspring distribution of a stem cell is given by \(\xi_s(x,y,z) = (p_sx + (1-p_s) y)^2\) and the offspring distribution of a mast cell is given by \(\xi_m(x,y,z) = (p_my+(1-p_m)z)^2\).

    At time \(\Delta t\), we can conclude

    \[\begin{align*} \Phi_s(x,y,z,\Delta t) &= (1-r_s\Delta t) x + r_s\Delta t \xi_s(x,y,z)\\ \Phi_m(x,y,z,\Delta t) &= (1-r_m\Delta t) y + r_m \Delta t \xi_m(x,y,z)\\ \Phi_e(x,y,z,\Delta t) &= z \end{align*}\]

    Following our standard argument, it follows that

    \[\begin{align*} \Phi_s(x,y,z,t+\Delta t) &= (1-r_s\Delta t) \Phi_s(x,y,z,t) + r_s\Delta t \xi_s(\Phi_s(x,y,z,t),\Phi_m(x,y,z,t),\Phi_e(x,y,z,t))\\ \Phi_m(x,y,z,t+\Delta t) &= (1-r_m\Delta t) \Phi_m(x,y,z,t) + r_m \Delta t \xi_m(\Phi_s(x,y,z,t),\Phi_m(x,y,z,t),\Phi_e(x,y,z,t))\\ \Phi_e(x,y,z,t+\Delta t) &= \Phi_e(x,y,z,t) \end{align*}\]

    So

    \[\begin{align*} \frac{\partial}{\partial t}\Phi_s(x,y,z,t) &= \lim_{\Delta t \to 0} \frac{\Phi_s(x,y,z,t+\Delta t)-\Phi_s(x,y,z,t)}{\Delta t}\\ &= \lim_{\Delta t \to 0} \frac{(-r_s\Delta t) \Phi_s(x,y,z,t) + r_s\Delta t \xi_s(\Phi_s(x,y,z,t),\Phi_m(x,y,z,t),\Phi_e(x,y,z,t))}{\Delta t}\\ &= r_s\xi_s(\Phi_s(x,y,z,t),\Phi_m(x,y,z,t),\Phi_e(x,y,z,t)) - r_s \Phi_s(x,y,z,t)\\ \frac{\partial}{\partial t} \Phi_n(x,y,z,t) &= \lim_{\Delta t \to 0} \frac{\Phi_m(x,y,z,t+\Delta t)-\Phi_m(x,y,z,t)}{\Delta t}\\ &= \lim_{\Delta t \to 0} \frac{(-r_m\Delta t) \Phi_m(x,y,z,t) + r_m \Delta t \xi_m(\Phi_s(x,y,z,t),\Phi_m(x,y,z,t),\Phi_e(x,y,z,t))}{\Delta t}\\ &= r_m\xi_m(\Phi_s(x,y,z,t),\Phi_m(x,y,z,t),\Phi_e(x,y,z,t)) - r_m \Phi_m(x,y,z,t)\\ \frac{\partial}{\partial t} \Phi_e(x,y,z,t) &= \lim_{\Delta t \to 0} \frac{\Phi_e(x,y,z,t+\Delta t)-\Phi_e(x,y,z,t)}{\Delta t}\\ &= 0 \end{align*}\]

    (b) Derive a forward Kolmogorov equation for \(\Phi(x,y,z,t)\).

    Solution (b)

    We have \(\Phi_s(x,y,z,t)\), \(\Phi_m(x,y,z,t)\) and \(\Phi_e(x,y,z,t)\). To find them at a time \(\Delta t\) later, we substitute \((1-r_s\Delta t)x + r_s\Delta t \xi_s(x,y,z)\) for \(x\), \((1-r_m\Delta t)y + r_m\Delta t \xi_s(x,y,z)\) for \(y\), and \(z\) for \(z\). We have

    \[\begin{align*} \Phi_s(x,y,z,t+\Delta t) &= \Phi_s((1-r_s\Delta t)x + r_s\Delta t \xi_s(x,y,z),(1-r_m\Delta t)y + r_m\Delta t \xi_s(x,y,z),z,t, z)\\ &= \Phi_s(x,y,z,t) + (r_s \Delta t)(\xi_s(x,y,z)-x)\frac{\partial}{\partial x} \Phi_s(x,y,z,t) + (r_m \Delta t)(\xi_m(x,y,z)-y)\frac{\partial}{\partial y} \Phi_s(x,y,z,t)\\ \Phi_m(x,y,z,t+\Delta t) &= \Phi_e((1-r_s\Delta t)x + r_s\Delta t \xi_s(x,y,z),(1-r_m\Delta t)y + r_m\Delta t \xi_s(x,y,z),z,t, z)\\ &= \Phi_m(x,y,z,t) + (r_s \Delta t)(\xi_s(x,y,z)-x)\frac{\partial}{\partial x} \Phi_m(x,y,z,t) + (r_m \Delta t)(\xi_m(x,y,z)-y)\frac{\partial}{\partial y} \Phi_m(x,y,z,t)\\ \Phi_e(x,y,z,t+\Delta t)&= z \end{align*}\]

    So

    \[\begin{align*} \frac{\partial}{\partial t}\Phi_s(x,y,z,t) &= \lim_{\Delta t \to 0} \frac{\Phi_s(x,y,z,t+\Delta t)-\Phi_s(x,y,z,t)}{\Delta t}\\ &= \lim_{\Delta t \to 0} \frac{(r_s \Delta t)(\xi_s(x,y,z)-x)\frac{\partial}{\partial x} \Phi_s(x,y,z,t) + (r_m \Delta t)(\xi_m(x,y,z)-y)\frac{\partial}{\partial y} \Phi_s(x,y,z,t)}{\Delta t}\\ &= r_s(\xi_s(x,y,z)-x)\frac{\partial}{\partial x} \Phi_s(x,y,z,t) + r_m(\xi_m(x,y,z)-y)\frac{\partial}{\partial y} \Phi_s(x,y,z,t)\\ \frac{\partial}{\partial t} \Phi_m(x,y,z,t) &= \lim_{\Delta t \to 0} \frac{\Phi_m(x,y,z,t+\Delta t)-\Phi_m(x,y,z,t)}{\Delta t}\\ &= \lim_{\Delta t \to 0} \frac{(r_s \Delta t)(\xi_s(x,y,z)-x)\frac{\partial}{\partial x} \Phi_m(x,y,z,t) + (r_m \Delta t)(\xi_m(x,y,z)-y)\frac{\partial}{\partial y} \Phi_m(x,y,z,t)}{\Delta t}\\ &= r_s(\xi_s(x,y,z)-x)\frac{\partial}{\partial x} \Phi_m(x,y,z,t) + r_m(\xi_m(x,y,z)-y)\frac{\partial}{\partial y} \Phi_m(x,y,z,t)\\ \frac{\partial}{\partial t} \Phi_e(x,y,z,t) &= \lim_{\Delta t \to 0} \frac{\Phi_e(x,y,z,t+\Delta t)-\Phi_e(x,y,z,t)}{\Delta t}\\ &= 0 \end{align*}\]

    (c) How can we interpret \(\Phi(0,0,1,t)\)? Use one of the Kolmogorov equations to write down an ordinary differential equation (that is, just \(t\) derivatives) that we can use to solve for this. What is the appropriate initial condition?

    Solution (c)

    This is the probability that at time \(t\) the only cells are end cells.

    Since we only allow \(t\) derivatives, this needs to use the Backward Kolmogorov Equations:

    \[\begin{align*} \frac{\partial}{\partial t} \Phi_s&= r_s(\xi_s(\Phi_s,\Phi_m,\Phi_e) - \Phi_s)\\ \frac{\partial}{\partial t} \Phi_m&= r_m(\xi_m(\Phi_s,\Phi_m,\Phi_e) - \Phi_m)\\ \frac{\partial}{\partial t} \Phi_e&= 0 \end{align*}\]

    The appropriate initial condition is \(\Phi_s=0\), \(\Phi_m=0\), and \(\Phi_e=1\).
